\# 個人部落格系統 (Java Web Blog)



\## 📖 專案簡介

這是一個基於 Java Servlet 與 JDBC 開發的全端個人部落格系統。實作了完整的文章 CRUD、Markdown 渲染、以及基於 Session 的管理員登入與權限控管。



\## 🛠️ 技術棧

\- \*\*後端\*\*：Java 21, Servlet, JDBC, MySQL

\- \*\*前端\*\*：HTML5, CSS3, Vanilla JavaScript

\- \*\*第三方套件\*\*：Gson, jBCrypt (密碼雜湊), Marked.js (Markdown 渲染), Highlight.js (語法高亮), DOMPurify (XSS 防護)



\## ✨ 核心功能

\- 管理員登入系統 (使用 Session 與 Filter 攔截未授權請求)

\- 文章發布、編輯、刪除 (整合 Markdown 編輯器與程式碼高亮)

\- 個人簡介編輯功能

\- 前後端分離架構 (使用 Fetch API 串接 RESTful API)

\- 密碼使用 BCrypt 雜湊加密，保障帳號安全
